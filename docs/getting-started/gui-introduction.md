# GUI 介面介紹

CASTLE 提供直觀易用的圖形使用者介面 (GUI)，讓不熟悉程式設計的使用者也能輕鬆進行動物行為分析。

## 🖥️ 啟動 GUI

### 方法 1: 命令列啟動
```bash
castle-gui
```

### 方法 2: Python 程式啟動
```python
import castle
castle.launch_gui()
```

### 方法 3: 從應用程式選單
安裝 GUI 版本後，您可以在系統應用程式選單中找到 "CASTLE Behavior Analysis" 圖示。

## 🎬 影片載入與預覽

### 載入影片檔案

1. **拖拽載入**: 直接將影片檔案拖拽到介面中
2. **選單載入**: `File → Open Video` 或使用快捷鍵 `Ctrl+O`
3. **批次載入**: `File → Add Multiple Videos` 載入多個檔案

![影片載入介面](../assets/screenshots/video-loading.png)

### 影片控制功能

| 控制項 | 功能 | 快捷鍵 |
|-------|------|--------|
| ⏯️ | 播放/暫停 | `Space` |
| ⏮️ | 跳到開始 | `Home` |
| ⏭️ | 跳到結束 | `End` |
| ⏪ | 後退 10 秒 | `←` |
| ⏩ | 前進 10 秒 | `→` |
| 🔊 | 音量控制 | `↑↓` |

### 影片資訊面板

右側屬性面板顯示：
- **檔案路徑**: 影片檔案位置
- **解析度**: 寬度 × 高度 (像素)
- **持續時間**: 總時長
- **幀率**: 每秒幀數 (FPS)
- **編碼格式**: 影片壓縮格式
- **檔案大小**: 影片檔案大小

#### 3. 偵測設定
```
🔍 Detection Settings:
   ├─ Sensitivity: ═══●═══ (靈敏度)
   ├─ Min Animal Size: 50 pixels
   ├─ Max Animal Size: 500 pixels
```

### 進階設定選項

??? info "進階參數設定"
    
    #### 追蹤參數
    - **Tracking Algorithm**: DeepSORT / SORT
    - **Detection Confidence**: 0.3 - 0.9
    - **NMS Threshold**: 非極大值抑制閾值
    
    #### 行為分析參數  
    - **Behavior Clustering**: 行為聚類演算法
    - **Time Window**: 行為分析時間窗口
    - **Smoothing Factor**: 軌跡平滑參數

## 🚀 執行分析

### 開始分析

1. **設定完成**後，點擊 `🚀 Start Analysis` 按鈕
2. **進度顯示**：底部狀態列顯示分析進度
3. **即時預覽**：可以在分析過程中預覽結果

![分析進度介面](../assets/screenshots/analysis-progress.png)

## 📊 結果檢視

### 行為時間軸

下方的行為時間軸顯示：
- **顏色編碼**：不同顏色代表不同行為
- **時間標記**：可點擊跳轉到特定時間點
- **行為標籤**：滑鼠懸停顯示行為詳情

```
探索行為  ■■■■■■░░░░■■■■■■■■░░░■■■■■■■■■■■■■■
靜止行為  ░░░░░░■■■■░░░░░░░░■■■░░░░░░░░░░░░░░
0s       30s      60s      90s      120s    150s
```

### 統計資訊面板

#### 基本統計
- **總分析時長**: 實際分析的影片長度
- **偵測到的動物**: 自動識別的動物數量  
- **軌跡總長度**: 動物移動的總距離
- **平均移動速度**: 整體平均移動速度

#### 行為統計
- **行為類型數量**: 識別出的不同行為模式
- **主要行為**: 佔時最長的前 3 種行為
- **活動/休息比例**: 活動時間與靜止時間比例

### 視覺化圖表

#### 1. 軌跡圖 (Trajectory Plot)
顯示動物在場地中的移動路徑：
- **軌跡線條**：顏色表示時間變化
- **熱力圖疊加**：顯示停留時間較長的區域
- **起始/結束點**：綠點 (開始) 和紅點 (結束)

#### 2. 速度變化圖 (Speed Over Time)
展示動物移動速度隨時間的變化：
- **X 軸**：時間 (秒)
- **Y 軸**：瞬時速度 (cm/s)
- **平均線**：顯示整體平均速度

#### 3. 位置熱力圖 (Position Heatmap)
顯示動物在不同區域的停留密度：
- **熱力顏色**：紅色 (高) → 藍色 (低)
- **區域標記**：標示實驗場地的特殊區域
- **密度數值**：滑鼠懸停顯示精確數值

#### 4. 行為分佈圖 (Behavior Distribution)
圓餅圖或長條圖顯示各種行為的時間佔比：
- **百分比標示**：每種行為的時間百分比
- **絕對時間**：具體的秒數或分鐘數
- **顏色編碼**：與時間軸顏色一致

## 🆘 常見操作問題

### 影片載入問題

??? question "影片無法播放怎麼辦？"
    **可能原因與解決方法**：
    
    1. **格式不支援**
       - 解決：轉換為 MP4 格式
       - 工具：使用 FFmpeg 或其他影片轉換軟體
    
    2. **編解碼器缺失**
       - 解決：安裝完整的多媒體編解碼器套件
       - Windows：K-Lite Codec Pack
       - macOS：安裝 VLC media player
    
    3. **檔案損壞**
       - 解決：嘗試使用影片修復工具
       - 或重新錄製影片

### 分析效果問題

??? question "動物偵測不準確？"
    **調整建議**：
    
    1. **提高偵測靈敏度**
       - 路徑：Settings → Detection → Sensitivity
       - 建議：從 0.5 調整至 0.7-0.8
    
    2. **調整動物大小範圍**
       - 根據實際動物在影片中的像素大小調整
       - 可以在影片中框選動物測量像素大小
    
    3. **檢查光線條件**
       - 確保影片光線充足且均勻
       - 避免陰影干擾

??? question "行為分類不合理？"
    **優化方法**：
    
    1. **調整行為聚類參數**
       - 增加時間窗口長度
       - 調整行為敏感度
    
    2. **自訂行為定義**
       - 使用進階設定中的自訂行為模式
       - 根據研究需求調整分類標準

## 🎓 GUI 使用技巧

### 快捷鍵大全

| 功能 | 快捷鍵 | 說明 |
|------|--------|------|
| **檔案操作** |
| 開啟影片 | `Ctrl+O` | 載入新的影片檔案 |
| 儲存專案 | `Ctrl+S` | 儲存當前分析專案 |
| 匯出結果 | `Ctrl+E` | 快速匯出分析結果 |
| **影片控制** |
| 播放/暫停 | `Space` | 影片播放控制 |
| 全螢幕 | `F11` | 全螢幕檢視影片 |
| 逐幀前進 | `→` | 單幀精確控制 |
| 逐幀後退 | `←` | 單幀精確控制 |
| **分析控制** |
| 開始分析 | `F5` | 快速啟動分析 |
| 暫停分析 | `F6` | 暫停當前分析 |
| 停止分析 | `Esc` | 終止分析程序 |
| **檢視控制** |
| 放大檢視 | `Ctrl++` | 放大影片或圖表 |
| 縮小檢視 | `Ctrl+-` | 縮小檢視 |
| 重設檢視 | `Ctrl+0` | 回復預設大小 |

### 效率提升技巧

#### 1. 專案管理
- **建立專案範本**：為常用的實驗類型建立設定範本
- **批次處理**：同時載入多個相似的影片進行分析
- **結果比較**：使用分割檢視同時檢視多個分析結果

#### 2. 參數調整策略
- **漸進式調整**：先使用預設值，再根據結果微調
- **A/B 測試**：對同一影片使用不同參數比較效果
- **參數記錄**：記錄最佳參數組合供未來使用

#### 3. 結果驗證
- **手動檢查**：對重要時間點進行手動驗證
- **統計一致性**：檢查統計結果是否符合預期
- **視覺確認**：結合軌跡圖和影片檢查分析準確性
