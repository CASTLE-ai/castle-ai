# 教學課程

歡迎來到 CASTLE 教學課程！這裡提供從基礎到進階的完整學習路徑，幫助您掌握動物行為分析的各種技能。

## 🎯 學習路徑

根據您的背景和需求，選擇適合的學習路徑：

**適合對象**: 第一次接觸動物行為分析的研究生

#### Phase 3: 鞏固練習

## 📚 課程模組

### 🧠 核心概念

深入理解 CASTLE 的理論基礎和技術原理。

| 課程 | 難度 | 時間 | 說明 |
|------|------|------|------|
| [CASTLE 架構](concepts/architecture.md) | 🌟 初級 | 20 分鐘 | 系統整體架構介紹 |
| [Focused Visual Latent](concepts/visual-latent.md) | 🌟🌟 中級 | 30 分鐘 | 核心視覺特徵提取技術 |
| [階層式聚類](concepts/hierarchical-clustering.md) | 🌟🌟 中級 | 30 分鐘 | 行為模式識別方法 |
| [演算法詳解](concepts/algorithm-deep-dive.md) | 🌟🌟🌟 進階 | 60 分鐘 | 深度演算法原理分析 |

### 🐾 物種別教學

針對不同動物物種的專門分析技巧。

| 物種 | 適用場景 | 特殊技巧 | 難度 |
|------|----------|----------|------|
| [小鼠](species/mouse-behavior.md) | OFT, EPM, MWM | 焦慮行為檢測 | 🌟 |
| [大鼠](species/rat-behavior.md) | 社交互動, 學習記憶 | 多動物追蹤 | 🌟🌟 |
| [果蠅](species/fly-tracking.md) | 求偶行為, 節律分析 | 微小物體追蹤 | 🌟🌟 |
| [線蟲](species/worm-analysis.md) | 運動模式, 趨化性 | 蛇形運動分析 | 🌟🌟🌟 |
| [魚類](species/fish-behavior.md) | 游泳模式, 群體行為 | 水中追蹤 | 🌟🌟 |

## 🛠️ 實作專案

通過完整專案鞏固學習成果：

### 初級專案
- **開放場行為分析**: 完整的 OFT 實驗分析流程
- **基礎統計報告**: 學會製作標準化的分析報告

### 中級專案  
- **多組別比較研究**: 藥物處理 vs 對照組的比較分析
- **時間序列分析**: 長期追蹤動物行為變化

### 進階專案
- **新行為模式發現**: 使用無監督學習發現新的行為模式
- **跨物種行為比較**: 不同物種間的行為模式比較分析

## 🏆 認證與評估

### 技能認證

完成不同難度的課程後，您可以獲得對應的技能認證：

- **🥉 CASTLE 基礎使用者**: 完成初級課程 + 基礎專案
- **🥈 CASTLE 進階使用者**: 完成中級課程 + 比較研究專案  
- **🥇 CASTLE 專家使用者**: 完成進階課程 + 創新應用專案

### 評估方式

- **理論測驗**: 線上選擇題和簡答題
- **實作評估**: 提交完整的分析專案
- **同儕評議**: 參與社群討論和知識分享

## 📅 建議學習計畫

### 週末速成班 (16 小時)
```
週六上午: 基礎概念 + 小鼠分析入門 (4小時)
週六下午: 實作練習 + 問題解決 (4小時) 
週日上午: 進階功能 + 參數優化 (4小時)
週日下午: 專案實作 + 總結回顧 (4小時)
```

### 每週漸進式學習 (4 週)
```
第1週: 基礎概念與基本操作 (4小時)
第2週: 單一物種深入分析 (4小時)
第3週: 多物種與比較分析 (4小時) 
第4週: 進階應用與專案實作 (4小時)
```

### 長期深度學習 (3 個月)
```
第1個月: 基礎到中級的循序漸進
第2個月: 進階功能與客製化開發
第3個月: 大型專案與研究應用
```
