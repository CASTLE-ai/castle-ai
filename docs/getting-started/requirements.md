# 系統需求

在安裝 CASTLE 之前，請確認您的系統滿足以下技術需求。

## 🖥️ 作業系統支援

| 作業系統 | 支援版本 | 狀態 | 備註 |
|---------|----------|------|------|
| **Windows** | Windows 10, 11 | ✅ 完全支援 | 推薦使用 Windows 10 1909+ |
| **macOS** | 10.15 (Catalina) 以上 | ✅ 完全支援 | 支援 Intel 和 Apple Silicon |
| **Linux** | Ubuntu 18.04+, CentOS 7+ | ✅ 完全支援 | 其他發行版通常也可正常運作 |

## 🐍 Python 環境

### 支援版本
- **Python 3.8** - 最低需求
- **Python 3.9** - 推薦
- **Python 3.10** - 推薦  
- **Python 3.11** - 最新支援

!!! warning "重要提醒"
    - Python 3.7 及以下版本不再支援
    - Python 3.12 正在測試中，可能有相容性問題

### 檢查 Python 版本
```bash
python --version
# 或
python3 --version
```

## 💻 硬體需求

### 最低需求配置

| 組件 | 需求 | 說明 |
|------|------|------|
| **處理器** | Intel i3 / AMD Ryzen 3 | 雙核心以上 |
| **記憶體** | 4GB RAM | 基本分析功能 |
| **硬碟空間** | 2GB | 包含依賴套件 |
| **顯示卡** | 無特殊要求 | 支援 1024x768 解析度 |

### 建議配置

| 組件 | 建議規格 | 效能提升 |
|------|----------|----------|
| **處理器** | Intel i7 / AMD Ryzen 7 | 多核心加速分析 |
| **記憶體** | 16GB+ RAM | 處理大型影片檔案 |
| **硬碟** | 20GB+ SSD | 快速讀寫影片資料 |
| **顯示卡** | NVIDIA GTX 1060+ | GPU 加速運算 |

### 高效能配置

| 組件 | 規格 | 用途 |
|------|------|------|
| **處理器** | Intel i9 / AMD Ryzen 9 | 大規模批次處理 |
| **記憶體** | 32GB+ RAM | 同時處理多個影片 |
| **硬碟** | NVMe SSD | 極速檔案存取 |
| **顯示卡** | RTX 3080+ / RTX 4070+ | 深度學習加速 |

## 🎬 影片檔案支援

### 支援格式

| 格式 | 副檔名 | 支援程度 | 備註 |
|------|--------|----------|------|
| **MP4** | .mp4 | ✅ 完全支援 | 最推薦格式 |
| **AVI** | .avi | ✅ 完全支援 | 傳統格式，檔案較大 |
| **MOV** | .mov | ✅ 完全支援 | Apple 常用格式 |
| **MKV** | .mkv | ✅ 支援 | 高品質影片容器 |
| **WMV** | .wmv | ⚠️ 有限支援 | Windows 專用格式 |

### 影片規格建議

| 參數 | 建議值 | 說明 |
|------|--------|------|
| **解析度** | 640x480 - 1920x1080 | 過低影響分析準確度 |
| **幀率** | 25-30 FPS | 標準動物行為分析 |
| **編碼** | H.264 / H.265 | 平衡檔案大小與品質 |
| **檔案大小** | < 2GB 單檔 | 記憶體限制考量 |

## 🌐 網路需求

### 初次使用
- **頻寬**: 100 Mbps+ (下載模型檔案)
- **流量**: 約 500MB (預訓練模型)
- **連線**: 穩定的網際網路連線

### 日常使用
- **離線使用**: ✅ 完全支援
- **雲端同步**: 可選功能
- **更新檢查**: 自動 (可關閉)

```txt
pandas >= 1.3.0

```

## ✅ 系統檢查工具

使用以下指令檢查您的系統是否符合需求：

### 基本系統資訊
```bash
# Python 版本
python --version

# 系統資訊 (Linux/Mac)
uname -a

# 記憶體資訊 (Linux)
free -h

```

```python
python check_system.py
```

## ⚠️ 常見問題

### Q: 我的系統不滿足最低需求怎麼辦？

A: 可以嘗試：
- 使用雲端運算服務 (如 Google Colab)
- 減少分析影片的解析度
- 使用精簡版本的 CASTLE

### Q: GPU 是必需的嗎？

A: GPU 不是必需的，但強烈建議：
- 沒有 GPU：分析速度較慢，但功能完整
- 有 GPU：速度提升 5-10 倍

### Q: 可以在虛擬機器中運行嗎？

A: 可以，但需注意：
- 分配足夠的記憶體 (建議 8GB+)
- 啟用硬體加速功能
- 確保顯示卡直通設定正確

---

!!! tip "系統優化建議"
    - 關閉不必要的背景程式
    - 定期清理暫存檔案
    - 保持系統和驅動程式更新
    - 使用 SSD 作為工作目錄
